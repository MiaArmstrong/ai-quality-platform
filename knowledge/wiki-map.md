## Rules

- Do not duplicate full Wiki content in memPalace.
- memPalace entries should link to the relevant Wiki page when one exists.
- If durable knowledge is promoted to the Wiki, update this map if it introduces
  a new major page.
- If Wiki documentation conflicts with current executable behavior, verify
  against the code and flag the documentation as potentially stale.
