# Definition of Done

Synthesize per work item. Do not paste boilerplate blindly.

## Story / New Feature / Improvement

- [ ] Acceptance criteria pass
- [ ] Code integrated into the intended branch
- [ ] Automated tests updated at appropriate layers
- [ ] Relevant end-to-end behavior verified
- [ ] No new build/type/lint failures
- [ ] Documentation updated
- [ ] Telemetry/observability updated if applicable
- [ ] Feature-flag/rollout behavior documented if applicable

## Bug

- [ ] Root cause identified
- [ ] Fix implemented
- [ ] Regression guard added
- [ ] Regression guard demonstrated to fail against the targeted regression when practical
- [ ] Fix verified in an appropriate environment
- [ ] Related defects/duplicates linked
- [ ] User-facing documentation/release note updated if necessary

## Task

- [ ] Deliverable matches objective
- [ ] Verification step passes
- [ ] No new build/type/lint failures
- [ ] Affected documentation updated

## Spike

- [ ] Question answered or uncertainty reduced
- [ ] Deliverable produced
- [ ] Decision recorded
- [ ] Follow-up work captured
