# Severity vs Priority

Severity and priority are separate dimensions.

## Severity

How bad is the technical/user impact?

Consider data loss/corruption, security/privacy exposure, functional blockage, blast radius, workaround availability, accessibility impact, and financial/compliance impact.

## Priority

How urgently should the organization address it?

Consider release blocking, SLA/customer commitment, business visibility, cost of delay, strategic importance, and mitigation/workaround availability.

A low-severity issue can be high-priority. A high-severity issue can have a lower immediate priority when mitigated.
