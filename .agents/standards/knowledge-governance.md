# Knowledge Governance

Keep agent memory useful without creating an uncontrolled second source of truth.

## Knowledge classes

### Working
Unvalidated or investigation-stage information.

Location: `knowledge/mempalace/`

### Validated operational
Evidence-supported knowledge useful for future work but not yet team-wide policy.

Location: `knowledge/mempalace/`

### Canonical shared
Stable, broadly reusable, team-facing knowledge.

Location: GitHub Wiki

## Promotion workflow

1. Discover
2. Record source/evidence
3. Validate
4. Deduplicate
5. Promote if broadly useful
6. Link working memory to canonical page
7. Remove redundant duplicated detail
8. Update `knowledge/wiki-map.md` when a new major Wiki page is introduced

Never store secrets, credentials, access tokens, private customer information, raw sensitive logs, or proprietary material in the public portfolio.
