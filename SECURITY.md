# Security Policy

AI Quality Platform is experimental portfolio engineering work and is not
production-ready software. It does not provide production support commitments.

## Reporting a security issue

Report security issues privately through GitHub's private vulnerability
reporting feature when it is available for this repository.

Do not submit secrets, credentials, private keys, sensitive logs, exploit
details, or other confidential information in a public GitHub issue.

If private vulnerability reporting is unavailable, contact the repository owner
through GitHub without including sensitive technical details in a public thread.
